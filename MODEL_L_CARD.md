## What it is

`P(listing gain)` for an Indian **mainboard** IPO, scored from final-day subscription at ~15:00 on the closing day, before the 4:00 PM broker cutoff. Two targets:

| Target | Label | Promised hit rate | Role |
|---|---|---|---|
| L1 | listing gain > 0% | **90%** | will it list above the issue price |
| L2 | listing gain > 10% | **80%** | is the gain worth the lock-up |

**There is one Model L** (decision H1). `L_day1`, `L_day2` and the final-day forecaster are cancelled — no permitted source publishes day-wise subscription history. A repo-wide search confirms **no day-wise or forecaster code path exists**, in this module or any other; there is nothing dormant to fall back to.

**Feature: `log1p(Total subscription)` alone (decision H11).** Issue size was **dropped**: its standardised coefficient is positive at every finite half-life (+0.314 at 2 y, +0.232 at 3 y, +0.112 at 5 y, +0.021 at 8 y) and negative only unweighted (−0.137), so its direction was set by the recency knob rather than by the data. Dropping it **raised** L1 pooled AUC (0.8112 vs 0.8081), left L2 unchanged (0.8808 vs 0.8809), and **fixed the one configuration where Set A failed** L2's Wilson gate. Set A is retained as a standing challenger on the A2 champion/challenger rule. **H11 supersedes A1 and H2 and needs ratification at Gate B.**

**No recency weighting (H11).** Pooled AUC is monotone in the half-life, so `none` is both the best setting and the end of the sequence: there is no knob left for a reader to question, which was the whole objection. Effective sample size equals the row count.

## Known limitations

1. **One model only (H1).** `L_day1`, `L_day2` and the final-day forecaster are cancelled: no permitted source publishes day-wise subscription history. Their code paths do not exist — there is nothing dormant to fall back to.
2. **Trained on 5pm final subscription, fed 3pm figures live — so it UNDERSTATES, and that makes it conservative (C3).** No historical 3pm snapshot exists, so the model is fitted on final-day subscription and then scored on the position at ~15:00. Institutional bids concentrate in the final hours (observed: Adroit Industries QIB 1.82x on day 2 against 195x at close), so a 3pm figure is systematically LOWER than the figure the model was trained on. The probability it returns is therefore too low, not too high: **the model will miss good IPOs rather than recommend bad ones.** A near-threshold `no` should be read as uncertain, not as a negative verdict. **The size of this bias is unmeasured** until the 15:00/17:30 paired capture accumulates data (`data/subscription_snapshots.csv`); it cannot be estimated from any existing source.
3. **Feature set is `log1p(Total)` alone (H11), superseding Set A.** Issue size was dropped: its coefficient is positive at every finite half-life and negative only unweighted, so its direction came from the recency knob rather than the data. Dropping it RAISED L1 pooled AUC (0.8112 vs 0.8081), left L2 unchanged (0.8808 vs 0.8809), and fixed the one configuration where Set A failed L2's Wilson gate. Set A is retained as a standing challenger on the A2 champion/challenger rule, never promoted by hand.
4. **The evidence for several rejected candidates is WEAKER than PLAN.md states.** Re-tested on the current dataset: the log transform improves pooled AUC by **0.07pp, not the 1.2pp** recorded in Amendment 02, so it is justified on distributional grounds and not by AUC; and `plus_hni` is **marginally better** (+0.26pp L1, +0.15pp L2), not worse as recorded. Market heat helps L1 (+0.53pp) and hurts L2 (-0.54pp), so the Set C challenger should be tracked per target. The feature choice still stands — every gap is under 0.6pp, inside this dataset's noise band — but the published figures should not be quoted as measured here.
5. **`retail_skew` is displayed, never modelled (H3).** Adding it moves pooled AUC by less than the noise band and it is already embedded in Total.
6. **Isotonic calibration (G1), and it overclaims (G2).** Among rows it places above the requirement it claims a mean 98.5% and delivers 94.0% (L1), and claims 99.2% and delivers 87.5% (L2). Reports must print the verdict and the threshold met, never the probability as a literal chance.
7. **No recency weighting (H11).** Pooled AUC rises monotonically as the half-life lengthens (L1 0.8051 at 2y to 0.8112 unweighted), so `none` is both the best setting and the end of the sequence. Every training row counts equally and there is no knob a reader could question. Effective sample size equals the row count.
8. `class_weight='balanced'` pushes probabilities towards 0.5; thresholds are validated on out-of-fold hit rates, not read off the probability scale.
9. Survivorship does not affect Model L: the target is realised on listing day for every IPO.
10. `Listing Gain` comes from the master dataset; whether it is the listing open or close is not documented in the source. The SME shadow model uses listing-day CLOSE — the two are not comparable.
